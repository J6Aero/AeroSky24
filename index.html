PROJECT DETAIL

AeroSky24 HealthAI
research study.

AeroSky24 HealthAI investigates aircraft engine Remaining Useful Life (RUL) prediction using the NASA C-MAPSS FD001 dataset. The project explores how machine-learning methods can support predictive maintenance by learning from operational sensor data and engine degradation trends.

The research focuses on understanding the data, preparing the modelling task, and comparing how different algorithms respond to the same engine-health problem. It does not claim a completed production system or a single best-performing model.

  • Random Forest
  • ANN
  • LSTM
Dataset NASA C-MAPSS FD001
Focus Engine RUL Prediction
Approach ML & Deep Learning

Research objectives

Explore how engine health can be modelled from sensor-driven degradation patterns and assess how different algorithms interpret the same prognostic task.

Data preparation

Review engine cycle progression, organise relevant variables, and define a suitable target for Remaining Useful Life estimation using the NASA dataset.

Models investigated

Random Forest, Artificial Neural Network (ANN), and Long Short-Term Memory (LSTM) are all explored as part of the research workflow.

Current project status

AeroSky24 HealthAI remains a research prototype focused on exploratory diagnostics, model comparison and learning in the aircraft engine prognostics domain.
